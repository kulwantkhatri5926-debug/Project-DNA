# Project DNA
A student project collaboration platform that helps students discover projects and teammates based on complementary skills, interests and availability.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy
Upload the contents of this folder to a GitHub repository and import it into Vercel. Framework preset: Next.js. No environment variables required.

## Prototype limitations
This frontend uses sample student profiles and transparent demo matching scores. Profile preferences, saved people, applications and created projects persist in browser localStorage. Real accounts, verified skills, messaging, AI recommendations and shared team workspaces require a backend.
